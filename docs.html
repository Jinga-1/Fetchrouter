How to use FetchRouter — and set up every gateway on it

Pick an offer, sign up through the link, pull the API key, and point your coding agent or chat client at it. Step-by-step for every gateway listed on the board.

01For visitors

FetchRouter is a board of AI gateways that give free credit on signup. You are scanning for two things at once: how much credit, and whether the gateway can be trusted. The board is built so you can decide before you spend an OAuth grant or a real signup.

Find an offer

  • Search — the box above the board matches gateway names, model names, tags, and descriptions. Type claude to see every gateway that routes Anthropic models, or github to see which ones need a GitHub login.
  • Filter — narrow by category (API router, chat gateway, first-party platform), by model class (wide catalogue, Anthropic only, Chinese models), or by status (verified, unverified, disputed).
  • Sort — default is highest rated, which pins featured offers to the top and then ranks by rating. Switch to most credit to rank purely by the dollar figure, or A → Z for an alphabetical sweep.

Start here: choose a verified, highly-rated gateway whose model class matches what you use — Anthropic-only for Claude Code, wide catalogue for anything. The default sort already puts those first.

02Reading a card

Credit

The signup grant in the unit the gateway stated — dollars, tokens, or unstated. The biggest number is not the best offer.

Verdict

Verified, unverified, or disputed. It carries the same visual weight as the dollar figure on purpose.

Outlook

Stable, developing, watch, or negative — the owner’s read on whether the offer will survive.

Rating

A 0–5 rating, or NOT RATED when the offer could not be graded. Unrated offers sort last.

Login

GitHub OAuth, Google OAuth, or any email. This is part of the true cost of a signup.

Cost of the click

The duty list — account-age rules, coding-agent-only restrictions, referral requirements. Read it before you sign up.

Status

Live, stale, or offline — probed automatically every day. Offline cards are dimmed and their signup button is disabled.

What the metadata means

  • Models — the routed catalogue as advertised. A short list is not automatically bad; a current model beats a long list of dead ones.
  • Model class — wide catalogue, Anthropic only, Chinese models, or first-party platform. Match it to your tool.
  • Tags — quick notes like $40 per referral or crypto accepted.
  • Checked — the last date the owner reviewed the offer. Offers change fast; treat anything older than a few weeks with extra caution.
  • Featured — the owner’s current best offer, pinned to the top of the default sort.

03Verdicts & ranking

The board publishes its own uncertainty. Every entry carries a verification verdict, and unverifiable offers are ranked accordingly — even though the site earns from the click either way.

The number is not the grade. A $200 claim that nobody could confirm ranks below a $70 grant that works. That is why the default sort is by rating, never by the dollar figure.

04Referral links

Every Get credit button opens the gateway’s signup page. Where the owner has set a referral code, it is appended to the URL as the gateway’s own query parameter (?aff=…, ?ref=…, ?invite_code=…).

  • Get credit — opens the signup URL (with the owner’s referral code when one is set) in a new tab.
  • Copy link — copies the same URL so you can share it or open it later. If no referral code is set, it copies the plain signup URL.

Disclosure. FetchRouter earns from signups reached through this page. The board says so plainly rather than burying it — treat the links accordingly.

05Set up your router

Each gateway below comes with its signup path, the credit you get, and how to configure it once you are in. The details are pulled live from routers.json, so this page always matches the board.

The general pattern: sign up through the link on the board → generate an API key in the dashboard → point your client at the gateway’s endpoint. For Claude Code, set ANTHROPIC_BASE_URL and ANTHROPIC_AUTH_TOKEN (or use a custom provider during login). For Codex, Cline, or anything OpenAI-compatible, use the gateway’s OpenAI-compatible endpoint with the same key.

06Live status

Every gateway is probed automatically once a day — no one checks by hand. The badge on each card tells you what the last probe found:

  • ● Live — the gateway answered the last check. Any HTTP response counts, so a bot-walled login page still counts as alive.
  • ● Stale — no successful probe in four days. The check pipeline may have stalled.
  • ● Offline — the probe could not reach it. The card is dimmed, its signup button is disabled, and it is treated as deprecated until a check clears it.

The line above the board shows the date of the last automatic check. If a gateway you care about is offline, check the gateway’s own site before giving up — temporary downtime happens.

07FAQ

Is the data verified?

Not by FetchRouter. Figures are third-party reported (seeded from the Router Watch board on 2026-08-31). Each card’s verdict is the owner’s confidence in a figure, and unverified figures are ranked accordingly.

Why is a bigger credit ranked lower?

An amount that could not be confirmed is worth less to you than one that works. Verification is part of the ranking, not decoration.

What does NOT RATED mean?

The owner chose not to grade that offer — usually because the amount or catalogue could not be established in any form. No grade is implied.

Which gateway should I set up?

Start with a verified, highly-rated offer whose model class matches your tool. For Claude Code or Codex, an Anthropic only or wide catalogue gateway covers you; for chat-only use, a chat gateway is enough. The default sort already puts the sensible candidates on top.

How do I use the same key in several tools?

One gateway key works everywhere that gateway supports — OpenAI-compatible endpoints work in Codex, Cline, OpenWebUI and custom clients; Anthropic-compatible endpoints work in Claude Code. Use the same key, just a different base URL.

Why is a card dimmed with an Offline button?

The daily probe could not reach that gateway. The card is kept visible (its credit terms still matter if it comes back) but is marked as deprecated until a future check succeeds.
